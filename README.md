# JUNIOR ENGLISH 1,085 V6

中学生向け英単語学習アプリ。GitHub Pagesでそのまま公開できる構成です。

## ファイル構成

- `index.html` — 画面構造
- `css/style.css` — デザイン / スマホレイアウト / バトル演出
- `js/words.js` — 1,085語の単語データ
- `js/app.js` — 一覧、検索、テスト、今日の50問、ボスクエストのロジック
- `.nojekyll` — GitHub Pages用

## V6変更点

- ボスクエストの通常攻撃 / 必殺を大きなタイル型ボタンへ変更
- スマホで押しやすいタップ領域に調整
- HTML / CSS / JavaScript / 単語データを分離
- V5の1.5秒以内2ダメージ、1.5〜3秒1ダメージ、必殺1回限定を維持

## GitHub Pages

このZIPの中身をリポジトリ直下へアップロードしてください。
Settings → Pages → Deploy from a branch → main / root で公開できます。
