# JUNIOR ENGLISH 1085 V5

中学生向け英単語学習アプリです。外部ライブラリ不要の静的HTMLで動作します。

## 主な機能
- 1,085語収録（英単語 / カタカナ読み / 日本語訳 / 学年目安）
- A-Z単語一覧
- 英語・日本語・カタカナ検索
- 10単語テスト
  - ミックス
  - 英語 → 意味
  - 意味 → 英語
- 今日の50問 + コイン報酬
- BOSS QUEST: SLIME
  - 自分HP 10 / スライムHP 20
  - 1問3秒
  - 通常攻撃: 1.5秒以内の正解=2ダメージ、1.5〜3秒=1ダメージ
  - ミス / 時間切れ=自分に1ダメージ
  - 必殺: 1バトル1回、難問6択、成功=4ダメージ

## GitHub Pagesで公開する方法
1. このZIPを展開します。
2. `index.html`, `README.md`, `.nojekyll` をGitHubリポジトリのルートにアップロードします。
3. GitHubの **Settings → Pages** を開きます。
4. **Deploy from a branch** を選び、`main` ブランチ / `/ (root)` を指定します。
5. 数分後にGitHub PagesのURLから起動できます。

## データ保存
コイン・今日の50問・ボススコア等はブラウザの `localStorage` に保存されます。

## 注意
カタカナ読みと学年区分は学習用の目安です。英語の実際の音声を完全に表すものではありません。
