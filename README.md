# JUNIOR ENGLISH 1535 V10

中学生向け英単語学習アプリ。GitHub Pagesでそのまま公開できる静的構成です。

## V10 追加
- スペル入力問題を追加
  - ⌨️ 意味 → スペル
  - 🎙️ 音声 → スペル
- 10問テストと「今日の50問」の両方で選択可能
- 大文字 / 小文字は区別せず判定
- スマホの英字入力向け設定
- Enter / 決定ボタンで即判定
- ヒントボタンで最初の1文字を表示
- 音声スペル問題では英単語を隠し、🔊を聞いて入力
- 正解 / 不正解後に英単語・カタカナ読み・意味・🔊発音を表示
- スペルミスも苦手単語システムへ自動登録
- リザルトに「自分が入力したスペル」と正解を表示

## 継承機能
- 1,535語
- 16ジャンル
- A-Z一覧・検索
- 10問テスト
- 今日の50問・コイン報酬
- 発音・リスニング
- 苦手 / 復習中 / 習得済み
- 間違えた問題リザルト
- BOSS QUEST / SLIME
- 1.5秒以内の通常正解 = 2ダメージ
- 1.5〜3秒 = 1ダメージ
- ミス / 3秒超過 = プレイヤー1ダメージ
- 必殺は1バトル1回、6択、成功4ダメージ
