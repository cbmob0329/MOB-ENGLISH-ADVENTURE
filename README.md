# JUNIOR ENGLISH 1535 V9

中学生向け英単語学習アプリ。GitHub Pagesでそのまま公開できる静的構成です。

## V9 追加
- 1,535語すべてを端末の英語音声で読み上げ可能
- 単語一覧に 🔊 発音ボタン
- 10問テストに5種類の問題タイプ
  - ミックス
  - 英語 → 意味
  - 意味 → 英語
  - 音声 → 意味
  - 音声 → 英単語
- 今日の50問にも同じ5種類を追加
- リスニング問題は英単語を画面に表示せず、音声を聞いて回答
- 答え合わせ・間違いリザルトからも発音を再生可能
- ボス戦の英単語表示問題にも 🔊 発音ボタン
- V8の苦手単語・習得度・ジャンル・スライム戦を継承

## 音声について
Web Speech API (`speechSynthesis`) を利用します。
追加の音声ファイルや外部APIは不要です。利用できる声質は端末・OS・ブラウザによって異なります。
iPhone / iPadでは、ユーザーが 🔊 ボタンをタップして再生する方式が最も安定します。

## GitHub Pages
リポジトリ直下にこのZIPの中身をアップロードしてください。

- `index.html`
- `css/style.css`
- `js/words.js`
- `js/app.js`
- `.nojekyll`

その後 GitHub の Settings → Pages から公開できます。
